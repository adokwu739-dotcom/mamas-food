# Mama's Food

A responsive food ordering website built with React and Vite.

## Planned features
- Browse meals, snacks, small chops, cakes and pastries, and drinks
- Search and filter the menu
- Add items to a shopping cart
- Prepare an order message for WhatsApp

## Development
Install dependencies with `npm install` and start the development server with `npm run dev` once the application files are in place.

Menu items, prices, food photos, contact details, and WhatsApp number are demonstration content and must be replaced with the vendor's real information before launch.
